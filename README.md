# Polaris — Browser-Based AI Cloud IDE

Write and run code directly in your browser, powered by AI. 
No setup. No local environment. Just open and build.

## Features
- Live code execution via WebContainers (no server needed)
- AI assistant powered by Gemini for code generation and explanation
- Import any GitHub repo and start editing instantly
- Export your changes back to GitHub
- Real-time terminal and preview panel

## Tech Stack
Next.js · TypeScript · Convex · WebContainers API · 
CodeMirror 6 · Vercel AI SDK (Gemini) · Inngest · Clerk · Octokit

## What I Built
This started from a Code with Antonio tutorial and was 
extended with original features including the GitHub 
import/export Inngest workflow, the useWebContainer hook 
architecture, and the AI integration layer.
